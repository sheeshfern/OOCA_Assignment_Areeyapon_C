# ตั้งชื่อความรู้สึก · ooca

The 2-Minute Mental Health Experience (ooca UX/UI Product Designer assignment)

ตอบ 4 ข้อ ใช้เวลาไม่เกิน 2 นาที แล้วได้การ์ดที่บอกว่า:

1. ตอนนี้คุณอาจกำลังรู้สึกอะไร
2. ความรู้สึกนั้นมาจากอะไร
3. ทำอะไรต่อได้ทันที

## Flow

| หน้า | สิ่งที่ทำ |
|---|---|
| S0 หน้าเริ่ม | เริ่มใช้งาน ไม่ต้องสมัคร สลับภาษาไทย/อังกฤษได้ที่มุมขวาบน (จำค่าไว้ในเครื่อง) |
| S1 | เลือกโทนความรู้สึก |
| S2 | เลือกคำ ไม่เกิน 2 คำ |
| S3 | เลือกว่ามาจากอะไร |
| S4 | เลือกว่าเป็นมานานแค่ไหน |
| S5 | การ์ดผลลัพธ์ |

- เลือกคำเสี่ยง เช่น "สิ้นหวัง" หรือ "เหนื่อยจนไม่อยากไปต่อ" จะข้ามข้อ 3–4 ไปหน้า S6 Safety ทันที หน้านี้มีปุ่มโทร 1323 และ 1669
- ทางแก้ไล่ระดับตามคำที่เลือกและระยะเวลา:
  - **เบา:** แนะนำสิ่งที่ทำได้ภายใน 30 วินาที
  - **กลาง:** แนะนำสิ่งที่ทำได้ทันที และเสนอนักจิตวิทยาเป็นทางเลือก
  - **นานกว่า 2 สัปดาห์:** ขึ้นปุ่มคุยกับนักจิตวิทยาก่อน

## Run

เป็นไฟล์ static ไม่ต้อง build:

- เปิด `index.html` ได้เลย
- หรือรัน `npx serve .` แล้วเปิด http://localhost:3000

## Deploy

1. import repo เข้า Vercel
2. ตั้ง Root Directory เป็น `web` และ Framework Preset เป็น "Other"
3. deploy ได้เลย ไม่ต้องตั้งค่าอะไรเพิ่ม

## Stack

- HTML, CSS และ vanilla JavaScript ในไฟล์เดียว ไม่มี dependency
- ฟอนต์ Prompt (Google Fonts) สำหรับภาษาไทย และ Gotham Rounded สำหรับอังกฤษและตัวเลข (ใช้ได้เมื่อเครื่องมีฟอนต์นี้ ถ้าไม่มีจะใช้ Prompt แทน)
- สีตาม ooca CI
- ภาพตัวละคร mooca อยู่ใน `assets/`
- "เก็บการ์ดไว้" บันทึกการ์ดเป็นรูป PNG ลงเครื่อง (มือถือเปิดหน้าแชร์) และเก็บบันทึกไว้ใน localStorage ของเครื่องผู้ใช้เท่านั้น ไม่ส่งข้อมูลไปที่ไหน

> แอปนี้ไม่ใช่การวินิจฉัย ถ้ารู้สึกไม่ปลอดภัย โทร 1323 (สายด่วนสุขภาพจิต) หรือ 1669
